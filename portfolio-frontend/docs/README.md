# BNB Web3 Portfolio Frontend 文档

目标：设计一个能展示三个区块链项目的前端作品集应用，视觉和交互符合主流币圈产品审美，同时服务求职场景。

这个前端不是普通个人主页，而是一个“Web3 Career Command Center”：让 HR 快速看到岗位匹配，让资深区块链开发能继续深挖架构、风险、测试和代码质量。

## 推荐产品定位

产品名：`BNB Web3 Career Terminal`

一句话定位：

> A crypto-native portfolio dashboard for presenting Web3 backend, Rust protocol, and Solidity vault engineering projects.

中文定位：

> 一个币圈产品风格的工程项目展示终端，用仪表盘、链路图、风险清单和面试视角展示 Web3 后端、Rust 协议和智能合约项目能力。

## 目标用户

- HR：需要 30 秒内判断候选人是否匹配 Web3 后端 / Rust Blockchain / Smart Contract 方向。
- 技术面试官：需要快速进入项目架构、实现深度、测试情况和风险修复路线。
- 候选人本人：需要在面试时用一个统一前端讲清楚三项目组合逻辑。

## 核心原则

1. 用币圈产品的界面语言讲工程能力，而不是做传统作品集。
2. 首屏必须像交易所/链上监控台，信息密度高但不混乱。
3. 每个项目都要有“HR 摘要”和“资深开发深挖”两种观看模式。
4. 不假装项目完美，要把验证状态、风险、修复路线展示出来，反而更可信。
5. 视觉上参考 Binance 的高对比深色金融感、Coinbase 的组件清晰度、DeFi dashboard 的模块化资产/指标表达。
