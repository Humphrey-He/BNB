# BNB Web3 Career Projects

本目录按三个求职方向拆成独立项目，每个项目的说明和规划都在对应的 `docs` 文件夹内：

1. [Web3 Backend / Blockchain Backend: multi-chain-asset-platform](./web3-blockchain-backend-engineer/docs/README.md)
2. [Protocol Engineer / Rust Blockchain Engineer: verifiable-rust-chain-node](./protocol-rust-blockchain-engineer/docs/README.md)
3. [Smart Contract Engineer: secure-yield-vault](./smart-contract-engineer/docs/README.md)

整体策略：

- 主线项目：`multi-chain-asset-platform`。用 Go/Rust/Python 后端背景切入 Web3 资产、钱包、交易生命周期、链上数据和基础设施岗位。
- 技术壁垒项目：`verifiable-rust-chain-node`。用 Rust、P2P、mempool、状态机、区块验证和 benchmark 支撑 Protocol / Rust Blockchain Engineer 方向。
- 安全补强项目：`secure-yield-vault`。不把自己包装成纯 Solidity 工程师，而是展示 Solidity、Foundry、安全测试、审计流程和链下协作能力。

当前调研依据：

- Web3 后端岗位仍高频出现 Go、Rust、Python、API、节点交互、链上数据处理、钱包/资产、实时系统和基础设施能力。
- Rust 区块链岗位通常集中在协议、节点、P2P、mempool、状态存储、Solana/Cosmos/以太坊客户端、MEV/DeFi 执行系统。
- 智能合约岗位对 Foundry、安全意识、审计流程、DeFi 攻击面、测试深度和权限边界要求很高，学习成本和责任风险都高于普通后端业务。
